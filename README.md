# RK Music Player

A responsive web-based music player built using HTML5, JavaScript, and Bootstrap.

## Features
- Audio Playback
- Playlist Support
- Search Functionality
- Dark Theme Interface
- Responsive Design

## Technologies Used
- HTML5
- CSS3
- JavaScript
- Bootstrap 5

## Project Objective
The project provides a simple and user-friendly music player interface for playing and managing audio files.
